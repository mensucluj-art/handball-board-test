# Handball Rotation Board

Prototype web app for live handball rotation, fatigue and substitution management.

Features:
- attack and defence permanently visible on the same court
- active phase selector for precise playing-time accounting
- player timers
- fatigue states: green / yellow / red / purple
- configurable thresholds per player
- recovery multiplier and minimum rest
- manual fatigue override
- 2-minute suspensions
- substitutions
- undo/reset
- local browser persistence
